강의 실습(Ch 04~06) 및 5대 타입 하네스 자동 실행을 위해 Python 3.10+ 및 uv를 전역 설치합니다.

🐍 1. Python 버전 확인 기본 런타임
터미널에서 버전 확인 (미설치 시 python.org에서 설치)
$ python --version
# Python 3.10 이상 필수
⚡ 2. uv 설치 (pip) 10~100배 속도
Rust 기반 초고속 패키지 관리자 uv 전역 설치
$ pip install uv
$ uv --version

Windows: powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
