PRO-TIP 01 가장 중요한 원칙

실전 팁 : 코드보다 '타입 규격'을 먼저 줘라

❌ 초보자의 실수:

"사용자 정보 받아서 DB에 넣고 결제 승인하는 API 만들어줘."

➔ AI가 필드명 제멋대로 지음 (`user_id` vs `userId`, 환각 발생)
✅ 프로 바이브 코더의 비결:

"아래 types.ts의 인터페이스 규격을 100% 만족하도록 구현해. 작업 완료 후 반드시 tsc --noEmit을 실행해 에러가 0건일 때만 완료 보고해."

💡 핵심 이점: 컴파일러가 Stderr 에러를 뿜으면 AI가 스스로 고칩니다. 인간이 에러를 읽고 디버깅할 필요가 없습니다.
LIVE ACTION 노트북에서 지금 바로 따라 하세요

실습 : 타입 정의 던지고 자가치유 시키기

Step 1. 타입 인터페이스 선언 (`types.ts`)
export interface PaymentOrder { id: string; amount: number; currency: 'KRW' | 'USD'; }
Step 2. AI 프롬프트 입력 (그대로 복사하여 에이전트에 전송)
"types.ts의 PaymentOrder를 인자로 받아 유효성을 검증하는 processOrder 함수를 order.ts에 작성해. 함수 작성 후 터미널에서 npx tsc --noEmit 을 실행하고, 타입 에러가 발생하면 직접 수정하여 성공할 때까지 반복해."
Step 3. 관전 포인트
AI가 환각으로 없는 필드를 쓰다가 ➔ tsc 에러를 맞고 ➔ 스스로 코드를 고쳐 0 errors로 수렴하는 자가치유 과정을 직접 목격하세요!
