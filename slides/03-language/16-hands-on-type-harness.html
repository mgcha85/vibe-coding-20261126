AI에게 코드를 맡길 때 반드시 쳐야 할 5대 안전망

1. Pydantic : 입출력 계약 강제 Fail-Fast

LLM의 JSON 환각과 키 누락 차단. Field(gt=0) 등 스키마 위반 시 즉각 에러 발생.

2. Pyright : 엄격 정적 타입 체커 Strict Type

AI의 빈번한 실수인 None 역참조, 잘못된 속성 접근을 런타임 전 0.1초 만에 적발.

3. import-linter : 아키텍처 계층 수호 No Spaghetti

도메인/모델이 UI나 컨트롤러를 역참조하는 순환 수렁 차단. contracts = "ui ➔ service ➔ domain" 단방향 강제.

4. Ruff : 초고속 정적 구문 세척 Rust Fast

AI가 남발하는 미사용 import, 포매팅 결함, 위험 구문을 0.01초 만에 자동 교정(ruff check --fix).

5. Pytest : 피드백 자가치유 루프 Self-Healing

테스트 실패 로그를 본 에이전트가 코드를 스스로 수정하여 100% All-Green까지 자율 수렴.

💡 통제 원칙: 인간이 코드를 검토하지 않습니다. 5대 하네스의 자동 피드백 루프가 AI를 통제합니다.

3. 아키텍처 역참조 ➔ import-linter가 계층 침범 및 순환 의존성 즉시 거부
4. 테스트 실패 ➔ AI가 pytest 실패 로그를 분석해 스스로 로직을 수정하여 All Passed 달성!
