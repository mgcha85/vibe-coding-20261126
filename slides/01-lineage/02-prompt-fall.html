1.1 프롬프트의 종말과 ReAct 패러다임

PAST : 1회성 생성 (Single-turn)

"완벽한 프롬프트"라는 환상

긴 프롬프트를 한 번에 던져 완성된 코드를 얻으려던 시도의 필연적 실패:

💥 문맥 중간 단절: 긴 코드를 출력하다가 중간에 토큰 제한이나 구조적 환각으로 중단
💥 환경 무시: 실제 파일 시스템, 패키지 버전, 컴파일러 에러를 보지 않고 맹목적으로 추측
"인간 개발자도 한 번에 무결점 1,000줄 코드를 짜지 않는다."
REVOLUTION : ReAct Framework

Reason + Act + Observe 루프

ReAct(Yao et al., ICLR 2023): LLM에게 '손(도구 실행)'과 '눈(결과 관찰)'을 부여한 시초.

Reason 상태 분석 및 다음 목표 추론
Act 파일 열람, 커맨드 실행 등 Tool 호출
Observe 터미널 출력 관찰 후 오차 궤도 수정
텍스트 생성이 아닌 '시스템 조작 상태 전이(State Machine)'로 진화
