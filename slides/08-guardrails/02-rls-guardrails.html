GUARDRAIL 01. DATABASE RLS DB 레벨 원천 차단

테이블 생성 즉시 RLS 강제 활성화

-- AI에게 마이그레이션 생성 시 무조건 포함시킬 룰
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can only see own orders"
ON orders FOR SELECT USING (auth.uid() = user_id);
  • • 프론트엔드 탈취 방어: 해커가 클라이언트 API 키를 뜯어내도 DB RLS가 타인 데이터 조회를 100% 거절.
  • • 에이전트 검증 룰: "모든 DDL SQL에 RLS 정책이 없으면 테스트 실패 처리하라"는 하네스 주입.
✓ 백엔드 API가 뚫려도 DB 자체가 방패를 들고 있는 구조
