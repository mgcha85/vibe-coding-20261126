PILLAR 01. .ENV 3원칙 환경별 분리

개발/상용 분리 & Git 완전 배제

실제 시크릿이 담긴 파일은 Git에 단 한 줄도 들어가선 안 됩니다. 템플릿만 커밋하고 실제 키는 런타임에 안전하게 주입합니다.

📁 .env.dev / .prod .gitignore 필수!
📁 .env.example 더미 템플릿만 커밋
# .env.example 예시
SUPABASE_URL=https://your-project.supabase.co
STRIPE_SECRET_KEY=sk_test_replace_this_here
  • • 프로덕션 주입: GitHub Secrets → SSH 배포 시 서버 직접 생성.
✓ .gitignore에 .env* 등록 여부를 매 커밋마다 자동 검증
PILLAR 02. 번들러 접두사 함정 브라우저 노출

VITE_ / NEXT_PUBLIC_ 평문 노출

모던 프론트엔드 빌더는 접두사가 붙은 환경변수를 자바스크립트 번들에 하드코딩합니다. 누구나 브라우저 DevTools에서 1초 만에 뜯어볼 수 있습니다.

❌ 치명적 실수 (전 세계 공개)
NEXT_PUBLIC_STRIPE_SECRET=sk_live_...
VITE_OPENAI_API_KEY=sk-proj-...
✅ 안전한 분리 (백엔드 전용)
STRIPE_SECRET_KEY=sk_live_... (서버만 읽음)
  • • 공개 가능: Supabase Anon Key, Toss Client Key, GA ID 등.
  • • 공개 절대 금지: 결제 시크릿, DB 비밀번호, LLM API 키.
⚠️ 접두사 하나 잘못 붙이면 회사 법인카드 즉시 정지
PILLAR 03. 커밋 전 원천 차단 Gitleaks Pre-commit

로컬 훅(Pre-commit) 시크릿 스캐닝

"사람이니까 실수할 수 있다"는 전제하에, 로컬 터미널에서 git commit을 치는 순간 정규식과 엔트로피로 시크릿을 감지하여 커밋을 강제 차단합니다.

# .pre-commit-config.yaml
- repo: https://github.com/gitleaks/gitleaks
rev: v8.18.2
hooks:
- id: gitleaks
> API Key 감지 시 Commit Aborted!
  • • Gitleaks: 150+개 클라우드/결제 API 키 시그니처 보유.
  • • Git 히스토리 보호: 한 번 커밋되면 rebase로 지워도 흔적 남음.
✓ 개발자의 손가락이 실수해도 기계가 커밋을 거절하는 안전장치
🛡️ 시크릿 철칙: "클라이언트 코드에는 오직 퍼블릭 식별자만, 결제 및 AI 모델 호출은 전용 백엔드 API에서만 수행한다."
