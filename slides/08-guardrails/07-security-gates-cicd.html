Chapter 08. 가드레일 · 8.6 자동화 보안 게이트 CI/CD Security Gate

CI/CD 4중 보안 게이트: PR 머지 전 자동 검증 파이프라인

AI가 수백 줄을 쏟아내는 시대에 인간의 눈(Code Review)만으로는 보안 취약점을 다 잡을 수 없습니다. 기계가 먼저 걸러야 합니다.

GATE 01. SECRET SCAN

Gitleaks 액션

커밋 및 PR의 모든 변경 사항(Diff)에서 정규식과 엔트로피를 대조하여 150+종의 API 키 및 비밀번호를 감지합니다.

- uses: gitleaks/gitleaks-action@v2
  env:
    GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
✓ 키 유출 감지 즉시 빌드 취소
GATE 02. CODE SAST

Ruff / Semgrep

소스 코드 정적 분석으로 SQL 인젝션, 위험한 exec/eval, 안전하지 않은 CORS, 하드코딩된 암호화 키를 자동 적발합니다.

# Bandit 보안 규칙 검사
uv run ruff check --select S .
semgrep scan --config auto
✓ OWASP Top 10 패턴 탐지
GATE 03. DB RLS LINT

Supabase DB Lint

새로 추가된 마이그레이션 SQL 파일에서 RLS 활성화 여부와 정책 누락 여부를 스키마 레벨에서 정밀 검증합니다.

# RLS 정책 누락 여부 검사
supabase db lint
# pgTAP 회귀 테스트 자동 구동
✓ 정책 누락 DDL 통과 원천 거절
GATE 04. DEPENDENCY

Dependency Review

새롭게 PR에 추가된 라이브러리가 취약점 DB(Advisory)에 등재되어 있는지, 라이선스 위반이 없는지 감시합니다.

- uses: actions/dependency-review-action@v4
  with:
    fail-on-severity: high
✓ 취약 패키지 머지 차단
🛡️ CI/CD 게이트 철칙: "4대 보안 게이트 중 단 하나라도 붉은 불(Fail)이 들어오면 Merge 버튼은 영구 비활성화된다."
