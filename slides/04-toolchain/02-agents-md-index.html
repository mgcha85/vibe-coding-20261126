AGENTS.md : 매 턴(Every-turn) 주입되는 프로젝트 헌법

매번 대화창에 장황한 지시를 복사해 넣지 마십시오. 루트의 AGENTS.md는 에이전트와 주고받는 모든 턴(Turn)마다 최상단에 자동 주입되는 단일 진실 공급원(SSOT)입니다.

⚡ 매 턴 자동 주입 메커니즘 Prompt Pipeline
💬
User Prompt (질문/지시)
"백테스트 결과 페이지 배포해줘"
Turn Start
↓ 🚀 시스템 레이어 자동 프리펜드 (Every Turn) ↓
📜 /AGENTS.md (프로젝트 헌법)
100% Guaranteed
  • 미션 & 스코프 (Mission & Scope)
  • 데이터 계약 (/mnt/data/finance 보존)
  • 빌드 & 품질 게이트 (uv sync, 린터, 테스트)
  • 배포 & 운영 규칙 (podman-compose, 포트)
↓
🧠
LLM 인지 컨텍스트 결합
System Rules + Skills Index + History + Intent
탈선 방지

📑 AGENTS.md에 반드시 기술해야 하는 4대 핵심 계약
1️⃣ Mission & Scope
프로젝트의 목표, 언어 스택 분업(Python 백테스트 vs Go 실시간 엔진), 산출물 저장 위치 정의.
2️⃣ Data Contract (데이터 계약)
절대경로 원칙(/mnt/data/finance), 임의의 데이터 폴더 오염 방지 및 Hive 파티션 보존.
3️⃣ Quality & Build Gates
uv sync, 린터 및 테스트 통과 의무화, 작업 전후 검증 커맨드 표준화.
4️⃣ Safe Change & Operations
파괴적 git 명령어 금지, .env 파일 커밋 엄금, 최소 단위 수정 및 LESSON_AND_LEARN 기록 의무.
🔗 실무 꿀팁: ln -s AGENTS.md CLAUDE.md 로 어떤 툴에서도 동일 사규 유지 Zero Discrepancy
