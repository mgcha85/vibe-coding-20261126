# 1. Mission & Architecture Scope

- Primary Goal: 대규모 트래픽 환경의 실시간 데이터 인텔리전스 및 추천 엔진 파이프라인 구축.
- Language Stack Split:
  • Research & AI Brain: Python 3.12 (모델 실험, 임베딩 벡터화, EDA)
  • Live Runtime Engine: Go 1.23 (초고속 gRPC 게이트웨이, Zero-Crash 24/7 스트리밍 파이프라인)
  • Frontend UI: SvelteKit + Tailwind CSS (실시간 관제 대시보드)
- Core Outputs: src/engine/ (Go 모듈), src/ai_model/ (Python 패키지), artifacts/reports/

# 2. Data Contract (데이터 계약 & 절대경로 엄수)

- Root Data Path: /data/corpus (절대경로 원칙; 임의의 상대경로나 /tmp 변조 엄금)
- Storage Layout: Hive Partition 구조 준수 (/data/corpus/events/dt=YYYY-MM-DD/hh=HH/)
- Agent Protocol:
  • 데이터 스키마 또는 파티션 컬럼을 임의로 변경하지 않고 사전문서와 일치시킬 것
  • 대용량 쿼리는 DuckDB / Polars 벡터화 엔진을 사용하여 메모리 OOM 방지

# 3. Quality & Build Gates (품질 검증 관문)

- Python Quality Gates:
  • 패키지 의존성 동기화: uv sync
  • 린트 & 정적 검사: uv run ruff check src/ tests/
  • 자동화 단위 테스트: uv run pytest -q tests/
- Go Quality Gates:
  • 빌드 및 린트: golangci-lint run ./...
  • 동시성 레이스 검사: go test -race -v ./...
- Verification Rule: 모든 PR 및 코드 변경 전 린트와 테스트가 100% 통과(Exit Code 0)해야만 작업 완료를 선언한다.

# 4. Safe Change Policy & Operations

- 파괴적 Git 행위 엄금: git push --force, git reset --hard 금지
- 시크릿 3계층 격리: API 키 및 DB 패스워드는 .env.dev / .env.prod 에만 기록하고 Git 커밋 절대 금지
- 컨테이너 배포: podman-compose up -d 로 무중단 서비스 롤아웃
- 트러블슈팅 아카이빙: 복잡한 버그나 설계 변경 발생 시 LESSON_AND_LEARN.md에 원인과 해결책을 필히 기록

💡 모든 AI 에이전트는 작업 시작 전 위 헌법을 읽고 절대 벗어나지 않습니다.
