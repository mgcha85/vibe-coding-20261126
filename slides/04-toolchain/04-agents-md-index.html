# AGENTS.md

PBMC 3k scRNA-seq 바이브 코딩 실습 저장소의 Every-turn 헌법이다. 모호하면 코딩 전에 역질문한다.

Every-turn SSOT
## 1) Mission & Scope
  • 목표: 10x PBMC 3k를 DuckDB 웨어하우스 ➔ 분석 파이프라인 ➔ Astro 시각화까지 재현 가능한 연구 앱으로 구축한다.
  • 범위: QC ➔ 차원축소/군집 ➔ 마커 ➔ 세포타입 추론 ➔ Astro 대시보드 + 로컬 로그인/회원(ops SQLite).
  • 범위 밖: 클라우드 배포, 다중 샘플 통합, 새 원시 데이터 다운로드(이미 data/raw/에 있음), OIDC/SSO.
## 2) Stack (강제)
규칙 위반 시 빌드 차단
층 기술 규칙
BE Python 3.12 + .venv uv로 패키지 설치
Warehouse DuckDB 분석 테이블·집계·내보내기만. 로그인/회원 금지
Ops DB SQLite (data/ops/app.sqlite) 회원·세션·감사 로그. 분석 행렬 금지
Auth API FastAPI (backend/auth) 기동 시 회원 메모리 적재; 변경 시 메모리➔SQLite sync; 로그는 비동기
Frame Polars (보조) SQL로 어색한 변환만. import pandas 금지
Graph ML scanpy / numpy / scipy / igraph PCA·neighbors·UMAP·Leiden·rank_genes_groups만
FE Astro 모든 단계 시각화는 Astro 페이지/컴포넌트
Charts Apache ECharts frontend/src/lib/echarts-setup.ts + ui-viz-*. 손수 SVG/타 라이브러리 금지
Methods explain /methods HTML 보드 + 단계 스키매틱 + 세포 퍼널 + 실행 타임라인. 웹 카피에 C4 레벨명·스택명 금지
UI light background 기본 .cursor/skills/ui-* 준수
🚫 금지 사항: pandas, Jupyter를 최종 산출물로 사용, matplotlib/seaborn PNG·손수 SVG를 Astro 차트 대체로 사용 (디버그 PNG는 results/만 허용).
## 3) Directory Ownership 
data/raw/             # 읽기 전용 원본 (h5ad)
data/warehouse/       # DuckDB 파일만 (BE 소유)
data/ops/             # SQLite ops DB (auth 소유)
backend/              # 분석 파이프라인 + auth API
frontend/             # Astro 앱 (시각화 SSOT)
frontend/public/data/ # DuckDB export JSON/Parquet
results/              # 요약 md/json (행렬 금지)
.cursor/skills/       # 절차 기억 SSOT

상세 트리는 스킬 data-analytics-source-tree를 참조한다.

## 4) Pipeline Order (절대 순서)
  1. 1. db-ingest-h5ad h5ad ➔ DuckDB 적재
  2. 2. data-analytics-eda 기본 EDA + ui-viz-eda (/eda)
  3. 3. data-analytics-qc QC 필터 + ui-viz-qc
  4. 4. data-analytics-dimreduce-cluster PCA / UMAP / Leiden + ui-viz-umap
  5. 5. data-analytics-markers DEG + ui-viz-dotplot / violin
  6. 6. data-analytics-celltype 마커 기반 세포타입 추론
  7. 7. data-analytics-export Astro용 아티팩트 갱신
⚠️ 철칙: 앞 단계 산출물 없이 뒷 단계를 구현하지 않는다. 오케스트레이션은 ops-pipeline-orchestration.
## 5) Context Load Order (코드 수정 전 엄격 로딩 순서)
1단계 AGENTS.md 본 헌법 문서
2단계 INTENT ➔ PLAN ➔ PROJECT 범위 · 계획 · 스택

5단계 대상 모듈 소스 최종 수정 작업
## 6) Grill-me

요구가 모호하면 구현 전 3~5개만 묻는다.
예: 어느 파이프라인 단계인지, 새 DuckDB 테이블인지 export 갱신인지, Astro 라우트 추가인지.

## 7) Quality Gates

.venv/bin/ruff check backend/
cd frontend && npm run build

커밋은 사용자 요청 시에만. .env 커밋 금지. rm -rf / DROP TABLE 파괴 명령 절대 금지.

난수 시드 & Auth 시드 random_state=0 / sc.settings.seed = 0 admin/admin123, viewer/viewer123 (실습용)
