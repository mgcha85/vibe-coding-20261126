에이전트의 '기억'은 모델의 지능이 아닌 툴체인의 인젝션 결과

1. STATELESS LLM (No Memory) : 완전한 기억 상실 Pure Function

LLM 가중치(Weights)는 요청 간 상태를 전혀 유지하지 못합니다. 이전 턴을 기억하는 것처럼 보이는 것은 매 요청마다 전체 맥락을 새로 전달하기 때문입니다.

2. EXTERNAL APPLICATION LAYER : 3대 외부 자산 3 Core Assets

• System Instructions: 최상위 헌법(AGENTS.md)과 행동 강령(RULES)
• User Preferences & History: 도메인 설정, 이전 대화 및 실행 결과 기록

3. CONTEXT INJECTOR : 매 턴 동적 깔때기 조립 Assembly Funnel

에이전트 런타임(Claude Code, Antigravity 등)은 매 턴마다 분산된 자산들을 '단 하나의 Context Window'로 합성하여 전송합니다.

💡 결론: 에이전트의 지능을 높이려면 프롬프트 미사여구가 아닌, 외부 툴체인(헌법·스킬·규칙)의 조립 파이프라인을 설계해야 합니다.
