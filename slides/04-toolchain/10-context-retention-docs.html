## [2026-11-08] Charts unified on ECharts
• Symptom: 손수 SVG 차트 4종이 제각각이라 상호작용 및 유지보수 비용 급증
• Root Cause: 초기 스캐폴드가 라이브러리 없이 수동 SVG로 시작
• Solution: echarts@5.6.0 + frontend/src/lib/echarts-setup.ts; violin은 custom series
• Lesson: ui-echarts가 차트 SSoT. 새 플롯도 ECharts만 사용.
## [2026-11-08] Scanpy Leiden default backend
• Symptom: sc.tl.leiden이 leidenalg 미설치로 실패하거나 느림 경고
• Root Cause: scanpy 1.12는 flavor 미지정 시 leidenalg 경로, igraph가 권장
• Solution: flavor="igraph", n_iterations=2, directed=False + igraph 패키지
• Lesson: 클러스터 단계는 data-analytics-dimreduce-cluster 파라미터 그대로 준수.
## [2026-11-08] pandas 금지와 AnnData
• Symptom: AnnData .obs/.var가 pandas DataFrame이라 변환 유혹
• Root Cause: 생태계 경계. warehouse SSOT는 DuckDB
• Solution: AnnData는 임시 수치 객체로만 쓰고, 표 산출은 즉시 DuckDB/Polars로 이관. 코드에 import pandas 금지
• Lesson: db-query-patterns의 "AnnData → DuckDB 브릿지"만 사용.

# INTENT.md · 핵심 연구 의도 & 인수 기준 (Intent SSoT) Design Intent

"왜 시스템이 이렇게 만들어졌는가"를 정의하여, 에이전트가 리팩토링 중 핵심 철학을 임의로 훼손하거나 불필요한 복잡성을 도입하는 것을 차단합니다.

## 1. Why & Persona
• Why: 단일세포 전사체(PBMC 3k) 표준 파이프라인을 바이브 코딩으로 재현하면서, AutoBA/scChat류 자연어→분석 흐름과 군집 해석을 연결.
• Persona: 생물정보학 입문 연구자 + 바이브 코딩 실습생. 한국어 UI로 QC·UMAP·마커를 한 페이지 흐름으로 확인.
## 2. Acceptance Criteria (인수 기준)
1) data/raw/pbmc3k_raw.h5ad를 재다운로드 없이 DuckDB로 적재한다.
2) import pandas가 코드베이스에 없다. 표 연산은 DuckDB(+ Polars 보조)만 쓴다.
3) QC → 군집 → 마커 → 타입 추론이 단계 모듈로 분리되고, 각 결과가 Astro에서 보인다.
4) 기본 UI는 light background. 차트는 Astro 컴포넌트(Apache ECharts 5)다.
5) 클러스터 해석은 마커 숫자 근거를 인용하며, T/B/Monocyte로 억지 분류하지 않는다.
# ADR.md · Architectural Decision Records (아키텍처 의사결정 기록) Architectural SSoT

## ADR-001: 분석 테이블/집계의 SSOT로 DuckDB 채택
Status: Accepted · Date: 2026-11-08
• Context (문제 상황): 2,700개 세포 × 32,738개 유전자 및 228만 개 발현 카운트 매트릭스를 지연 없이 SQL 쿼리하고 Astro 정적 아티팩트로 내보내야 함. SQLite는 대용량 컬럼 집계에 느리고, PostgreSQL은 서버 데몬 설치 필요.
• Decision (결정 사항): DuckDB 임베디드 OLAP 엔진을 웨어하우스 SSOT로 채택. 표 연산은 DuckDB(+ Polars 보조)만 쓰고 pandas 전면 금지.
• Consequences (결과 및 트레이드오프):
- 장점: 추가 DB 데몬 설치 없이 단일 파일(pbmc3k.duckdb)로 228만 카운트 집계 0.05초 달성.
- 제약: AnnData 객체와의 경계에서 db-query-patterns 브릿지 패턴을 반드시 준수해야 함.
💡 세션이 끊겨도 이 5대 문서를 읽은 에이전트는 0초 만에 이전 맥락을 100% 복원합니다.
