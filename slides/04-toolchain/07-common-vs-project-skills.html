공통 모듈과 프로젝트 특화 : AGENTS.md vs PROJECT.md

모든 프로젝트에 똑같은 룰을 복붙하면 유지보수가 불가능해집니다. 전사 공통 스킬과 도메인 특화 규칙을 깔끔히 분리해야 합니다.

🌐 전사 공통 모듈 (Global / Cross-Project)
Symlink · Submodule

회사나 팀의 모든 레포지토리에서 100% 동일하게 공유되는 표준 거버넌스 문서와 범용 스킬 팩입니다.

📜 AGENTS.md (공통 헌법) 루트 심볼릭 링크
• .env 시크릿 관리, 배포 게이트, 커밋 컨벤션, 공통 파괴적 명령어 금지 룰.
• 중앙 사규 저장소(harness-collection)에서 Git Submodule/심볼릭 링크로 연결.
📂 skills/ (공통 스킬 팩) 범용 자동화
• uiux-governance: 사내 공통 디자인 시스템/Tailwind 색상 토큰.
• deployment-operations: podman-compose, CI/CD 공통 파이프라인.
💡 중앙 집중식 장점: 사내 코딩 컨벤션이나 보안 가이드가 바뀌면 중앙 레포 수정 하나로 모든 프로젝트에 즉시 동기화!
🎯 프로젝트 특화 모듈 (Project-Specific)
Local Repository Only

해당 레포지토리 고유의 비즈니스 도메인, 데이터 스키마, 특화 파이프라인만 격리하여 기술하는 전용 문서입니다.

📋 PROJECT.md (프로젝트 특화 정의서) 🔍 클릭: 예시 보기
• 현재 시스템의 비즈니스 목표: "10x Genomics PBMC 3k 단일세포 전사체 파이프라인"
• 이 프로젝트만의 데이터 계약: data/raw/pbmc3k_raw.h5ad, DuckDB 웨어하우스 스키마.
📂 skills/data-analytics-* (도메인 특화 스킬) 해당 레포 한정
• db-duckdb-schema: 2,700개 세포 × 32,738개 유전자 DuckDB 정규화 DDL.
• data-analytics-dimreduce-cluster: HVG 2,000, PCA 50, Leiden resolution 1.0 군집 연동.
💡 도메인 격리 원칙: 공통 사규(AGENTS.md)를 더럽히지 않고, 각 프로젝트의 특수성을 독립적으로 보존!
📋 PROJECT.md · 10x Genomics PBMC 3k scRNA-seq 단일세포 전사체 실전 정의서 (Domain SSOT) 생물정보학 도메인 특화
# 1. Project Identity & Runtime Scope

- Project Name: pbmc3k-vibe-lab
- Domain: scRNA-seq / PBMC cell-type clustering (단일세포 전사체 분석 및 세포타입 판정)
- Execution Runtime:
  • Backend: Python 3.12 (.venv, uv 패키지 동기화)
  • Frontend: Astro 5 (frontend/, pin astro@5.16.6; Node 22.22 호환)
  • Warehouse SSOT: data/warehouse/pbmc3k.duckdb

# 2. Seed Data Contract & Dependency Policy

- Seed Data: data/raw/pbmc3k_raw.h5ad (2,700 세포 × 32,738 유전자, raw count matrix, hg19)
- Allowed BE: duckdb, polars, scanpy, anndata, numpy, scipy, scikit-learn, igraph, umap-learn, h5py, pyarrow, ruff
- Forbidden (절대 금기): import pandas 전면 금지, pyspark, dask dataframe, jupyter를 산출 경로로 사용하는 행위 금지

# 3. Single-Cell Analysis Defaults (분석 알고리즘 표준)

- Random Seed: seed = 0 / sc.settings.seed = 0
- QC 필터링 기준: 미토콘드리아 유전자 접두사 MT-, pct_counts_mt < 5 AND 200 <= n_genes_by_counts < 2500, min_cells = 3
- 정규화 & 차원축소: target_sum = 1e4, HVG = seurat top 2000, PCA n_comps = 50, neighbors n_neighbors = 15, n_pcs = 30
- 군집 & 마커 추출: Leiden resolution=1.0, flavor=igraph, n_iterations=2, rank_genes_groups method = wilcoxon, use_raw=True

# 4. Canonical Marker Panel & ECharts UI SSoT

- 표준 세포 마커 패널 (SSOT):
  IL7R, CD3D, CD3E, CD8A, CD8B, MS4A1, CD79A, CD14, LYZ, S100A8, FCGR3A, MS4A7, GNLY, NKG7, FCER1A, CST3, PPBP
- 타입 판정 규칙: Wilcoxon 상위 유전자 중 하우스키핑(RPS/RPL/MT-) 제외 후 canonical marker 평균 발현으로 판정.
- UI Visualization SSoT: Astro 컴포넌트 내 Apache ECharts 5 (echarts-setup.ts); UMAP 산점도, 바이올린 custom series, 닷플롯 차트 일원화 (손수 SVG나 Plotly 금지).

💡 공통 헌법(AGENTS.md) 아래에 각 도메인의 핵심 비즈니스 규칙(PROJECT.md)이 완벽히 독립 보존됩니다.
