토큰의 실체 : 1개 빈 문서에 조립되는 5대 컨텍스트 파이프라인

LLM은 이전 대화를 스스로 기억하지 못하는 완전한 상태 비저장(Stateless) 엔진입니다. 매 턴마다 '단 하나의 빈 문서'에 헌법, 규칙, 스킬, 압축 이력, 질문이 실시간으로 조립되어 API로 전송됩니다.

📦 5대 독립 원천 자산 (Sources) Modular Inputs
📜
1. AGENTS.md
프로젝트 헌법, 아키텍처, 데이터 계약
불변 헌법 ➔
⚖️
2. rules (.cursorrules)
개발자 행동 지침, .env 보호, 코딩 컨벤션
시스템 규칙 ➔
🧩
3. Triggered Skills
호출된 SKILL.md만 선별 로드 (Lazy-loaded)
선택 주입 ➔
🗜️
4. Compacted History
이전 턴 요약본 (불렛 포인트 & 세션 요약)
압축 이력 ➔
💬
5. Current Turn (질문+로그)
이번 턴 프롬프트 + 터미널 에러/코드 diff
동적 꼬리 ➔
💡 토큰의 진실: 5개 자산이 각각 존재하는 것이 아니라, 에이전트 런타임이 하나의 거대한 텍스트 스트림으로 단일 합성하여 LLM 엔드포인트로 전송합니다.
