Chapter 04. 툴체인 · 4.7 토큰의 실체와 프롬프트 조립 구조 CONTEXT WINDOW ASSEMBLY · TOKEN PIPELINE

토큰의 실체 : 1개 빈 문서에 조립되는 5대 컨텍스트 파이프라인

LLM은 이전 대화를 스스로 기억하지 못하는 완전한 상태 비저장(Stateless) 엔진입니다. 매 턴마다 '단 하나의 빈 문서'에 헌법, 규칙, 스킬, 압축 이력, 질문이 실시간으로 조립되어 API로 전송됩니다.

📜 토큰 동작의 본질: 에이전트의 기억은 마법이 아니라, 매 턴마다 '1장의 빈 문서에 헌법 + 스킬 + 압축 이력 + 질문을 모듈러 합성'하는 파이프라인입니다.
