TOOLCHAIN BLUEPRINT Modern Engineering Stack
① 절차 기억 (Procedural)
➔ AGENTS.md + Skills (.skills/)

프로젝트 헌법을 매 턴 주입하고, ui-*, ops-* 등 작업별 상세 절차(SOP)를 온디맨드로 로드.

② 의미/일화 기억 (Semantic & Episodic)
➔ LLM-Wiki & Context Cache

대화 세션이 끊겨도 프로젝트 아키텍처 결정(ADR)과 트러블슈팅 시행착오 기록(LESSON_AND_LEARN)을 지속 영속화.

③ 작업 기억 보호 (Working)
➔ Aside (독립 사이드카 에이전트)

수만 줄의 서버 로그 분석이나 코드베이스 전체 서베이를 백그라운드 서브 에이전트로 격리 실행하여 메인 창 오염 차단.

④ 행동 상호운용성 (Action)
➔ MCP (Model Context Protocol)

사내 데이터베이스, 깃허브, 슬랙, 결제 PG API를 표준화된 JSON-RPC 프로토콜로 어떤 LLM에든 플러그인 연결.
