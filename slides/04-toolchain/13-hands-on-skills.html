Chapter 04. 실전 실습 · 4.11 하네스 구축

실전 팁 & 바로바로 실습 : 워크스페이스 문서 세팅 & 사규 심기

⏱️ 5분 실습 (Hands-on)

에이전트가 작업 전 스스로 읽을 5대 필수 추적 문서를 터미널에서 1초 만에 세팅하고, 나만의 스킬(SKILL.md)을 만들어 AI가 스스로 지침을 따르는지 관전합니다.

PRO-TIP · HARNESS DISCIPLINE Zero Prompt Philosophy

실전 팁 : 매번 프롬프트 복붙하지 말고 'Skill'로 구워라

❌ 초보자의 실수: 새 세션마다 "우리는 Svelte 쓰고, .env 분리하고, 다크 테마 Bento 그리드로..." 10줄씩 프롬프트 타이핑 ➔ 토큰 낭비 및 3턴 뒤 망각.
✅ 프로 바이브 코더의 비결: .cursor/skills/ui-dashboard/에 마크다운 하나만 두면, 설명 1초도 안 해도 사규를 100% 준수합니다.
⚡ 실습 1 5대 필수 추적 문서 일괄 생성 (터미널 1초 세팅)
기존 파일 안전 보존

.cursor/ 폴더와 AGENTS.md는 실습 팩으로 이미 탑재되어 있으므로 제외하고, 나머지 5대 핵심 문서(LESSON, PLAN, ROADMAP, INTENT, ADR)를 기존 파일 손상 없이 안전하게 생성합니다.

🍎 macOS / Linux (Bash · Zsh) [ -f "$doc" ] || touch
for doc in LESSON_AND_LEARN.md PLAN.md ROADMAP.md INTENT.md ADR.md; do [ -f "$doc" ] || touch "$doc"; done
🪟 Windows (PowerShell · Windows Terminal · Cursor) Test-Path New-Item
"LESSON_AND_LEARN.md", "PLAN.md", "ROADMAP.md", "INTENT.md", "ADR.md" | ForEach-Object { if (-not (Test-Path $_)) { New-Item $_ -ItemType File } }
※ CMD(명령 프롬프트) 사용 시: for %f in (LESSON_AND_LEARN.md PLAN.md ROADMAP.md INTENT.md ADR.md) do if not exist %f type nul > %f
✓ 실행 즉시 워크스페이스 루트에 5대 추적 문서가 세팅되어 에이전트 탈선을 원천 방어합니다.
⚡ 실습 2 나만의 UI 스킬(SKILL.md) 생성 & 에이전트 자율 준수 관전
3-Step Walkthrough
Step 1. 스킬 문서 작성: .cursor/skills/ui-dashboard/SKILL.md 규칙 정의
---
name: ui-dashboard
description: "대시보드 UI 생성 시 16:9 다크 테마와 Bento 카드를 강제한다"
---
# 규칙: 배경색은 bg-slate-950, 카드는 bg-slate-900/80 및 border-slate-800을 쓸 것.
Step 2. 채팅창에 딱 한 줄만 프롬프트 입력 Zero Prompt
"PBMC 3k 세포 군집 대시보드 화면 하나 만들어줘"
Step 3. 관전 포인트 (에이전트의 자율 준수) Autonomous Sync
"다크 테마로 해줘", "Bento 스타일로 해줘"라고 말하지 않았는데도, 에이전트가 방금 생성한 ui-dashboard/SKILL.md를 스스로 찾아 읽고, 다크 Bento 카드로 코드를 뽑아냅니다!
