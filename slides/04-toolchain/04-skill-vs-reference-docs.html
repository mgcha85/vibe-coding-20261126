문서 설계학 : SKILL.md vs REFERENCE.md 분리

모든 규칙을 하나의 파일에 다 넣으면 토큰이 폭발하고 인지 부하가 생깁니다. 1단계 경량 실행 규칙과 2단계 심층 레퍼런스로 계층화해야 합니다.

📄 Level 1 : SKILL.md (실행 헌법 & 트리거)
Always Loaded on Trigger

name: uiux-governance

---

- Unified Experience, Approach with One-Click, Catch on One-Page
# 2. 10대 상시 상호작용 표준 (Always UX Patterns)
- 아이콘 우선(Icon-First), 인라인 액션, 완료 시 자동 접힘, 패널 스크롤 강제
✓ YAML Frontmatter 필수: name과 description이 에이전트의 트리거 지표
✓ 초경량 유지: 토큰 낭비를 막고 에이전트의 핵심 작업 지침만 전달
⚡ 핵심 역할: 에이전트가 "내가 지금 무엇을 지켜야 하는지" 즉각 행동 방향을 잡는 스위치

# CHEATSHEET.md · Agent Runtime CLI & Verification Cheatsheet Dev CLI SSoT

에이전트가 어떤 빌드 도구나 검증 명령어를 호출해야 할지 즉각 복사/실행할 수 있는 명령어 집합입니다.

## 1. Python Environment & Quality Control
uv sync # lockfile 기반 의존성 완벽 동기화
uv run ruff check src/ --fix # PEP-8 린트 및 AST 자동 수정
uv run pytest -q tests/ # 단위 테스트 초고속 검증 (Silent mode)
## 2. Go Runtime & Race Condition Auditing
golangci-lint run ./... # 엄격한 멀티 린터 정적 분석
go test -race -v ./cmd/... # 런타임 데이터 레이스 100% 감지
go build -o bin/engine ./cmd/ # 무의존성 경량 바이너리 컴파일
## 3. Container Orchestration & Daemon Control
podman-compose -f compose.dev.yml up -d # 데브 컨테이너 백그라운드 구동
podman logs -f --tail 100 engine-daemon # 실시간 에이전트 로그 스트리밍
# CHECKLIST.md · Production 10-Gate Deployment Checklist Release Gate

에이전트가 "배포 완료되었습니다"라고 보고하기 전, 스스로 통과해야 하는 10가지 필수 검증 체크리스트입니다.

[Gate 1] Secret Isolation: .env 및 API 토큰이 Git에 커밋되지 않았는가? (gitleaks 통과)
[Gate 2] Absolute Path: /data/corpus 절대경로 외 임의의 로컬/상대경로 참조가 없는가?
[Gate 3] RLS Security Audit: 모든 신규 PostgreSQL 테이블에 Row Level Security 활성화 완료
[Gate 4] Concurrency Race Test: Go 백엔드에 go test -race 실행 시 0 Warning 통과
[Gate 5] Graceful Shutdown: SIGTERM 수신 시 진행 중인 작업을 5초 내 정상 드레인하는가?
[Gate 6] LESSON_AND_LEARN: 발생했던 트러블슈팅 및 버그 원인이 마크다운에 문서화되었는가?
# ALGORITHM.md · Real-time Hybrid Ranking & Decay Scoring Math & Logic

에이전트가 추천·검색 알고리즘을 코딩할 때 임의로 가중치를 변경하지 않도록 수식과 시간 감쇠 상수를 명시한 문서입니다.

## 1. Hybrid Score Formulation
Score(d, q, t) = α · CosineSim(E_q, E_d) + (1-α) · Quality(d) · exp(-λ · Δt)
• α = 0.65 : 벡터 임베딩 유사도 반영 가중치
• λ = 0.048 : 반감기 14.4시간 기준 시간 감쇠 계수 (Time-decay factor)
• Δt : 현재 시각과 문서 생성 시각의 차이 (단위: Hours)
## 2. Latency Budget & SLA Contract
• Max Candidate Heap Size: K = 250
• P99 Latency SLA: < 12.5ms (5,000 QPS 동시 요청 환경 기준)
# SCHEMA.md · PostgreSQL DDL & Strict RLS Policies Database DDL

데이터베이스 테이블 컬럼명, 외래키, 인덱스 및 테넌트 데이터 격리를 위한 RLS 보안 정책 SSoT 문서입니다.

-- Table Definition (Workspaces & Agent Logs)
CREATE TABLE agent_execution_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID NOT NULL REFERENCES workspaces(id),
  agent_role VARCHAR(64) NOT NULL,
  prompt_tokens INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT clock_timestamp()
);
-- Row Level Security (Tenant Isolation)
ALTER TABLE agent_execution_logs ENABLE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON agent_execution_logs
  USING (workspace_id = current_setting('app.workspace_id')::uuid);
