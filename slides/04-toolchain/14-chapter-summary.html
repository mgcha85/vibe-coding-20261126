Chapter 04 핵심 요약 : 도구와 기억의 인프라 체계

에이전트를 길들이는 비결은 프롬프트 작문술이 아닙니다. 헌법(AGENTS), 절차(Skills), 규칙(Rules), 파이프라인(Hooks), 위키(Wiki)의 5대 인프라 결합입니다.

📜 1. CONSTITUTION
AGENTS.md · 네이밍
Every-turn 자동 주입 매 턴마다 시스템 프롬프트 최상단에 강제 주입되어 AI의 환각과 탈선 원천 차단.
도메인 접두사 (Prefix) ui-*, ops-* 명확한 폴더 네이밍으로 키워드 라우팅 정밀화.
✓ 사규 강제 Zero Prompt Drift
📄 2. DOCUMENTS
SKILL vs REF · Rules
2단계 문서 계층화 SKILL.md는 50줄 초경량 로드, 세부 명세는 REFERENCE.md 온디맨드 열람.
/grill-me 역질문 에이전트가 섣불리 코드를 짜지 않고 기획 인터뷰를 먼저 진행해 예스맨 증후군 타파.
✓ 토큰 최적화 Intent Alignment
🪝 3. HOOKS & STATE
Hooks · 3대 문서
물리적 실행 차단 PreToolUse로 파괴적 명령 차단, PostToolUse로 린터 가동, Stop Hook으로 품질 보증.
영속성 삼각편대 LESSON(오답) + PLAN(상태) + INTENT(의도)로 세션 단절 극복.
✓ 자동 가드레일 State Persistence
🧠 4. WIKI & CURATION
LLM-Wiki · 큐레이션
중앙 위키 지식 누적 전 프로젝트가 단일 위키를 공유하며 Multi-Depth 원자 단위 분할로 스킬 상충 제거.
개발 표준화 & 원샷 내 아키텍처 취향을 표준화하여 "단 1줄 프롬프트로 완성형 소프트웨어" 달성.
✓ 10x 토큰 레버리지 One-Prompt Production
