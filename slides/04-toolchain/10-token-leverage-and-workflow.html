Chapter 04. 툴체인 · 4.9 토큰 레버리지 TOKEN LEVERAGE · ZERO-PROMPT BOOTSTRAP

토큰 레버리지 : 지시는 줄이고, 산출물 범위는 넓힌다

누적된 LLM-Wiki를 바탕으로 신규 프로젝트를 시작할 때 PLAN, INTENT, PROJECT만 구성하면 같은 토큰으로 10배 넓은 업무를 초고속 달성합니다.

📈 토큰 레버리지 플라이휠 (Token Leverage)
Efficiency Curve

과거에는 프로젝트가 커질수록 설명해야 할 프롬프트가 늘어났지만, 중앙 위키 체계에서는 프롬프트 지시량이 기하급수적으로 줄어듭니다.

❌ 위키 없는 일반 개발자 (Zero Leverage) 프롬프트 2,000 토큰 소모
매번 "SvelteKit 써주고, Tailwind 다크 테마 색상 코드는 #0f172a 쓰고, .env.dev 만들고, 테스트는 vitest 쓰고..." 장황하게 타이핑 ➔ 토큰 소진으로 실제 코드 작성 컨텍스트 부족.
✅ LLM-Wiki 보유자 (10x Token Leverage) 프롬프트 30 토큰 소모
"PLAN.md 2단계 대시보드 화면 구현해줘" 딱 한 문장 지시 ➔ 에이전트가 위키의 디자인 토큰, 린터, 테스트 룰을 스스로 꺼내어 1,970 토큰 분량의 완벽한 프로덕션 코드 생성!
🚀 결과: "같은 20만 토큰 컨텍스트 안에서 AI가 순수하게 코드 합성에만 95% 이상의 에너지를 집중"
🚀 신규 프로젝트 킥오프 3단계 프로토콜
Standard SOP

새 프로젝트를 시작할 때 코드를 먼저 치지 마십시오. 중앙 위키를 연결한 뒤 단 3개의 앵커 문서만 세팅하면 준비 끝입니다.

Step 1. 중앙 위키 심볼릭 링크 연결 0초 부트스트랩
ln -s /shared/harness-collection/AGENTS.md ./AGENTS.md
ln -s /shared/harness-collection/skills ./.cursor/skills
Step 2. 3대 앵커 문서 초기 구성 설계 앵커링
• PROJECT.md: 도메인 목표, 고유 데이터 경로 정의.
• INTENT.md: 기술 스택 선정 배경(ADR) 기록.
• PLAN.md: 구현 마일스톤 4단계 체크리스트 작성.
Step 3. 1줄 지시 & 결과 점검 자율 주행
에이전트는 헌법과 위키를 바탕으로 일체의 군더더기 없이 마일스톤 순서대로 정확한 결과물을 산출합니다.
💡 이 프로토콜을 통하면 1시간 안에 기획부터 배포 가능한 서비스까지 무중단 개발 가능!
⚡ 토큰 레버리지 공식: 누적된 LLM-Wiki + 3대 앵커 문서(PROJECT · INTENT · PLAN) = 최소 입력으로 최대 프로덕션 완성.
