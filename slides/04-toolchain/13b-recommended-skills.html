이름 (Skill Name & Link) 설명 (Core Philosophy & Features)
🧠 i-have-adhd ↗
출력 제어 · Yap 제거
에이전트의 불필요한 미사여구(yap)와 장황한 서론/결론을 제거하는 고효율 생산성 스킬
장황한 설명 대신 즉시 실행 가능한 명령어, 직접적인 코드 수정본, 핵심 조치 결과만을 군더더기 없이 출력하도록 강제합니다. 토큰 낭비를 줄이고 집중력을 유지하며 빠른 템포로 코딩할 때 필수적입니다.
🎯 pstack ↗
모델 라우팅 · 예산 최적화
서브에이전트 역할별 최적 모델 및 추론 예산(Reasoning Budget) 동적 자동 구성
아키텍트(Plan), 코더(Coder), 리뷰어(Reviewer), 테스터(Test) 등 각 역할에 맞춰 가장 가성비 높고 강력한 모델 조합과 추론 예산을 자동으로 매핑합니다. 다중 에이전트 운용 시 비용 절감과 품질 보장을 동시에 달성합니다.
📊 ppt-master ↗
슬라이드 · 시각화 자동 생성
마크다운 및 기획 문서로부터 전문적인 고품질 프레젠테이션(PPT/웹 슬라이드) 자동 제작
복잡한 요구사항이나 기술 기획서를 분석하여 16:9 반응형 인터랙티브 웹 슬라이드나 PPTX 덱으로 체계적으로 변환합니다. 다이어그램 배치, 핵심 키워드 강조 등 슬라이드 엔지니어링 과정을 원클릭으로 가속화합니다.
⚡ superpowers ↗
OS 도구 · 에이전트 역량 확장
Claude Code 및 Cursor 에이전트에 강력한 터미널 · 브라우징 · 시스템 도구 세트 주입
기본 에이전트 환경의 한계를 넘어, 복잡한 시스템 제어, 브라우저 자동화, 데이터 수집, 파이프라인 연동 등 고난도 태스크를 자율적으로 완수할 수 있도록 실전 도구 체계와 안전 실행 수칙을 결합해 줍니다.
🔬 reverse-engineering-anything ↗
바이너리 · 소스코드 역공학
바이너리, 레거시 소스코드, 비공개 프로토콜 및 API에 대한 체계적 역공학 분석
문서화되지 않은 내부 로직, 실행 파일, 패킷 구조를 단계별로 역추적하여 데이터 흐름 다이어그램과 표준 명세서(Spec)로 복원합니다. 레거시 시스템 마이그레이션이나 프로토콜 분석 시 폭발적인 위력을 발휘합니다.
📜 Skills 원칙: 모든 걸 직접 만들지 말고, 검증된 오픈소스 스킬 생태계를 지렛대로 삼아 개발 속도를 비약적으로 높이십시오.
