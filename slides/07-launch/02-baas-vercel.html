SUB-CHAPTER 7.2

Vercel의 Preview 배포 자동화

AI 에이전트의 브랜치 푸시마다 격리된 테스트 URL 실시간 발급:

1. Git Push 이벤트 트리거 에이전트가 생성한 브랜치가 푸시되면 즉시 Next/Svelte 빌드
2. 격리된 Preview URL 생성 app-git-feat-auth.vercel.app에서 실제 브라우저 렌더링 검증
3. 1초 Instant Rollback 장애 발생 시 클릭 한 번으로 이전 빌드로 즉시 복구
"말보다 작동하는 라이브 URL을 직접 보며 피드백하는 속도"
