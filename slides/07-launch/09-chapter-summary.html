Chapter 07 핵심 요약 : 프로덕션 4대 방어선

"인증 · 결제 · 배포 · CI/CD"의 4대 기둥을 견고히 세움으로써, 1인 개발자도 글로벌 상용 서비스를 안정적으로 운영할 수 있습니다.

🔑 1. AUTH & RLS

Supabase Auth

직접 구현을 배제하고 관리형 BaaS로 완전 격리.

SNS OAuth 원클릭 활성화 구글 · 카카오 5분 연동으로 복잡한 세션 로직 제거.
Row Level Security (RLS) auth.uid() = user_id로 DB 레벨에서 권한 격리.
📋 체크리스트:
[x] SNS OAuth · RLS 활성화
[x] JWT LocalStorage 저장 금지
⚠️ 주의: JWT 시크릿을 프론트에 노출 시 전 유저 DB 탈취 위험
✓ 5만 MAU 평생 무료 Zero Auth Code
💳 2. BILLING

Toss · PayPal · Stripe

위젯 SDK와 웹훅 기반의 안전한 3단계 수납 체계.

결제 위젯 SDK 연동 카카오 · 토스 · 네이버페이 · 해외카드 원클릭 지원.
서버 Confirm & Webhook HMAC 서명 검증 및 orderId 멱등성으로 위조 차단.
📋 체크리스트:
[x] 카드번호 저장 절대 금지(PG 위임)
[x] Footer 약관 3종 · 사업자정보 명시
⚠️ 주의: 프론트 성공 화면만 믿고 권한 부여 금지(Webhook 필수)
✓ PCI-DSS 규정 준수 Legal Ready
☁️ 3. HOSTING

Vercel · Cloud Run · VM

성격별 분업(UI vs API vs 24/7 Bot) 최적화.

Vercel (Frontend PaaS) 글로벌 엣지 CDN 캐싱 및 브랜치 프리뷰 URL.
GCP Cloud Run · VPS API는 Scale-to-Zero($0), 봇은 상시 가동 VM(Podman).
📋 체크리스트:
[x] Budget Alert $1 등록 (과금 방어)
[x] .env 파일 .gitignore 격리
⚠️ 주의: 백엔드 API를 Vercel 서버리스에 올려 긴 폴링 금지
✓ 월 10만 트래픽까지 $0 Scale-to-Zero
🚀 4. CI/CD

GitHub Actions

푸시 즉시 테스트-빌드-배포 전 과정 자동화.

CI 품질 게이트 (Lint · Test) Ruff, Pytest 통과 시에만 브랜치 병합 허용.
CD 무중단 자동 릴리즈 SSH Action + ./start.sh prod로 30초 내 배포.
📋 체크리스트:
[x] SSH Key GitHub Secrets 등록
[x] 배포 스크립트 멱등성 검증
⚠️ 주의: 배포 서버에 SSH 직접 접속해 소스 수정(`vim`) 금지
✓ Git Push = Live 2,000 Min Free
