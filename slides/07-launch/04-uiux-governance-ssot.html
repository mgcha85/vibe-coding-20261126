Chapter 07. 런칭 · 7.3 클라이언트 거버넌스 UI/UX GOVERNANCE · SSOT · 10 ALWAYS PATTERNS

프로덕션 UI/UX 거버넌스 : AI의 프론트엔드 난개발을 통제하는 SSoT

AI 에이전트에게 프론트엔드 개발을 맡길 때 발생하는 디자인 파편화와 화면 난개발을 차단하는 Single Source of Truth (SSoT) 표준 체계.

⚠️ Vibe Coding UI 3대 붕괴 에이전트 한계
1. 디자인 토큰 파편화 화면마다 마진, 버튼 크기, 폰트, 상태 컬러가 제각각 생성되어 조잡한 느낌 가중.
2. 거대 폼 방치 & 맥락 소실 설정이 끝나도 수십 개 입력창이 그대로 남아있고, 화면을 이동하며 작업 맥락 파탄.
3. 브라우저 스크롤 붕괴 창 전체 스크롤이 생겨 헤더와 내비가 밀려 올라가고, 비동기 로딩 시 깜빡임 발생.
🎯 3대 핵심 철학 (Core Principles) SSoT 원칙
① Unified Experience (일관된 경험) 모든 화면 컴포넌트, 색상, 상태를 단일 토큰 체계(SSoT)로 일원화.
② Approach with One-Click (원클릭 접근) 목적 액션까지 클릭 뎁스 최소화, 필드 옆 인라인 액션 적극 배치.
③ Catch on One-Page (원페이지 종결) 화면 이동 없이 패널 분할과 독립 스크롤로 단일 뷰 내 업무 종결.
📐 10대 상시 상호작용 표준 (10 Always UX Interaction Patterns)
Do vs Don't 표준 규격
1. 아이콘 우선 (Icon-First Status) DO

연결/정상 상태는 긴 텍스트 배지 나열 대신 컬러 아이콘 칩 + 툴팁으로 간결화.

2. 인라인 액션 (Inline Actions) DO

필드 아래 별도 버튼 행 금지. 인풋/셀렉트 우측에 복사·새로고침 인라인 아이콘 배치.

3. 완료 시 자동 접힘 (Auto-Collapse) DO

설정 완료 후 거대한 입력 폼 방치 금지. Accordion 요약 카드로 자동 전환.

4. 패널 단위 독립 스크롤 (Panel Scroll) DO

창 전체 스크롤 금지. h-screen overflow-hidden 셸 고정 후 패널 내부 스크롤.

5. 얇은 크롬 (Thin Chrome) DO

장황한 상단 배너 금지. 헤더는 48~56px 단일 행으로 최소화하여 업무 공간 극대화.

6. 전제조건 액션 게이트 (Action Gating) DO

미완성 상태 클릭 후 alert 금지. 필수 조건 미충족 시 버튼 disabled + 사유 툴팁 제공.

7. 작업 이력 영속성 (History Persistence) DO

새로고침 시 초기화 금지. 최근 조회, 탭, 입력값은 로컬/세션 스토리지에 복원 유지.

8. 기본 언어 한국어 (Korean Default) DO

불필요한 영어 남발("Pending", "Success") 금지. "대기 중", "정상 연결" 등 한국어 표준.

9. 초기 번쩍임 방지 (No Premature Flash) DO

로딩 0.5초 동안 "데이터 없음" 문구 깜빡임 방지. Skeleton UI 또는 로딩 가드 적용.

10. 외부 클릭 자동 닫기 (Click-Outside) DO

드롭다운/팝오버는 문서 외부 영역 클릭 시 자동으로 닫히는 리스너 필수 구현.
