Chapter 06. 비용 · 6.1 토큰 90% 세이브 아키텍처

Prompt Caching & 계층형 모델 라우팅

컨텍스트 구조를 '고정 헤더 + 동적 바디'로 재설계하면 매 턴마다 발생하는 토큰 비용이 극적으로 줄어듭니다.

TECHNIQUE 01. PROMPT CACHING 입력 토큰 80~90% 할인

고정 컨텍스트를 캐시 라인 상단에 배치

🔒 [CACHED] 시스템 프롬프트 + SKILLS.md + types.ts (30k 토큰)
➔ 2번째 턴부터 90% 요금 감면 ($0.03 ➔ $0.003)
📝 [DYNAMIC] 이번 턴의 유저 요청 및 최근 diff (1k 토큰만 과금)
  • • 프롬프트 순서의 중요성: 자주 바뀌는 내용(날짜, 질문)을 상단에 두면 캐시가 전부 깨집니다.
  • • 캐시 친화적 배치: 불변 규격(규칙, API 문서)을 무조건 맨 앞에 고정하세요.
결과: 50턴 동안 대화해도 첫 턴 수준의 저렴한 비용 유지
TECHNIQUE 02. MODEL ROUTING Pro 1회 + Flash 100회

두뇌 모델 vs 손발 모델의 계층 분리

🧠 Pro Model (Opus / Pro) 기획 · 아키텍처 설계 (1회)
⚡ Flash Model (3.0 Flash) 코드 작성 · 단위 테스트 (100회)
  • • 단순 구현의 낭비 방지: 오타 수정, 린트 교정에 최고가 모델을 쓰는 것은 돈 낭비입니다.
  • • 속도 5배 향상: Flash 모델은 응답 속도가 0.5초 수준으로 생산성이 폭발합니다.
결과: 월 100만 원 나오던 API 청구서가 월 7만 원으로 수직 낙하
💡 실무 원칙: 설계는 비싼 모델(Pro)에게 1번 맡기고, 코드 타이핑과 테스트는 가장 빠르고 싼 모델(Flash)에게 100번 시키세요.
