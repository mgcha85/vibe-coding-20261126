Chapter 06. 비용 · 6.6 실전 토큰 세이빙 도구 SELECTIVE GREP · LOG TRUNCATION · REPOMIX

실전 토큰 다이어트 툴킷 : Ripgrep & 에러 로그 Truncation

파일을 다 열어보지 말고 Grep으로 표적 타격하고, 실패 시 로그의 머리(Head)와 꼬리(Tail)만 주입하여 토큰 누수를 원천 봉쇄합니다.

🔍 1. TARGETED GREP
view_file 남발 금지
❌ 나쁜 습관: 변수 하나 찾겠다고 500줄 파일 전체를 view_file로 읽기 (매번 3,000 토큰 낭비).
⚡ 프로의 표적 타격: grep_search로 매칭 라인과 전후 3줄(-C 3)만 정확히 조회 (30 토큰으로 100배 압축!).
💻 실전 CLI 명령어: $ rg -n -C 2 "func HandleAuth" internal/
✓ 파일 읽기 토큰 95% 절감 Selective Search
✂️ 2. LOG TRUNCATION
스택트레이스 다이어트
❌ 수천 줄 에러 덤프: 테스트 실패 시 2,000줄의 라이브러리 내부 스택트레이스를 다 보내면 모델이 압사당함.
⚡ Head 15 + Tail 15 법칙: 에러의 원인이 적힌 최상단(Head 15줄)과 실제 실패 코드 라인(Tail 15줄)만 주입하고 중간 프레임워크 로그는 컷!
💻 실전 파이프라인: $ go test ./... 2>&1 | head -n 25
✓ 컨텍스트 오염 원천 방지 Error Clarity
📦 3. REPOMIX IGNORE
코드 팩 엄격 필터링
❌ 락 파일 & 에셋 참사: package-lock.json (5만 줄), 바이너리, SVG를 그대로 먹이면 100만 토큰 순삭.
⚡ .ignore 화이트리스트: repomix --ignore "*.lock,dist/*,assets/*"로 순수 비즈니스 로직만 추출하여 토큰 85% 다이어트.
💻 repomix.config.json: "ignore": { "patterns": ["*.lock", "dist/*"] }
✓ 노이즈 0% 순수 코드 팩 Pure Context Pack
🛠️ 실무 도구 테이크어웨이: Grep 표적 타격 + 로그 Truncation + Repomix 필터링의 3종 도구로 매 턴 낭비되는 수만 토큰을 차단하십시오.
