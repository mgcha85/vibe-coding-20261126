Chapter 06. 비용 · 6.2 토큰 다이어트 스킬 CAVEMAN · PONYTAIL SKILLS

출력 다이어트 & 과잉 방지 : caveman & ponytail 스킬

AI의 공손한 미사여구를 쳐내는 caveman(출력 70% 삭감)과 주니어식 과잉 엔지니어링을 막는 ponytail(게으른 시니어 사다리)로 토큰 누수를 원천 봉쇄합니다.

🦴 caveman 스킬 : 출력 토큰(Output) 다이어트
Why use many token

"Certainly! I'd be happy to help..." 같은 공손한 인사말과 서술형 수식어는 출력 토큰을 낭비하고 개발자 읽기 피로만 유발합니다.

❌ 일반 AI 응답 (120 토큰 소모):
"물론입니다! 문의주신 리액트 컴포넌트가 계속 리렌더링되는 원인은 내부에서 새로운 객체 참조를 생성하기 때문입니다. 이를 해결하려면..."
⚡ caveman 장착 응답 (22 토큰, 82% 삭감):
"인라인 객체 = 매 렌더마다 새 참조 생성 = 리렌더링. useMemo로 래핑."
보존 법칙: 코드, 에러 메시지, CLI 플래그, API 명칭은 100% 유지 Code Intact
/caveman lite (문장 유지) /caveman full (단문/키워드) /caveman ultra (극단)
✓ 출력 토큰 65~75% 절감 및 실시간 스트리밍 대기 단축 Zero LLM Slop
👱 ponytail 스킬 : 과잉 엔지니어링 박멸
Lazy Senior Mindset

AI는 날짜 선택기 하나 만드는데 새 npm 패키지 깔고 300줄 보일러플레이트를 짜려 합니다. 가장 좋은 코드는 작성하지 않은 코드입니다.

🪜 The Ladder of Laziness (게으른 시니어 사다리) 위에서 멈추기
1. YAGNI: 진짜 필요한가? (스킵)
2. REUSE: 레포 기존 코드 재사용
3. STD LIB: 언어 표준 라이브러리
4. NATIVE: 브라우저/OS 네이티브
5. DEPS: 기존 설치된 패키지
6. ONE-LINE: 한 줄 구현 가능한가?
➔ 7단계: 위 조건 모두 실패할 때만 최소한의 신규 코드 작성!
/ponytail-review (오버엔지니어링 diff 제거) /ponytail-audit (기술부채 탐지)
✓ 신규 의존성 0건 & 누적 컨텍스트 비대화 80% 사전 차단 Less Code, Less Tokens
🚀 출력과 생성의 다이어트: caveman으로 AI의 입을 줄이고, ponytail로 AI의 손을 줄여 토큰과 코드베이스를 가볍게 유지하십시오.
