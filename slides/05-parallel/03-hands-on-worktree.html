실전 팁 & 바로바로 실습 : Worktree로 2명 동시 지휘

⏱️ 5분 실습 (Hands-on)
PRO-TIP 03

실전 팁 : Worktree + 서브에이전트 법칙

❌ 흔한 병목: 백엔드 API 만드는 동안 멍하니 대화창 기다리기 (15분 소요).
➔ 인간의 시간이 AI 대기 시간에 묶임.
✅ 프로 바이브 코더의 비결: Worktree를 따서 백그라운드 태스크나 별도 에이전트에게 넘겨두고, 메인 디렉토리에서는 프론트엔드 UI를 계속 빌드합니다. 작업 시간 1/3 단축!
💡 이 레포의 AGENTS.md 규격에도 Workspace: 'branch'로 격리 작업실을 자동 생성하도록 정의되어 있습니다.
LIVE ACTION 노트북 터미널에서 지금 바로 입력하세요

실습 : 1초 만에 격리 작업실 생성하고 분신 띄우기

Step 1. 터미널에서 워크트리 생성 (1초 소요)
git worktree add ../wt-auth -b feat/auth
➔ 디스크 복제 없이 ../wt-auth 폴더에 완벽히 격리된 작업실이 생성됨
Step 2. 새 터미널/에이전트에 작업 지시
cd ../wt-auth && "auth.ts 모듈을 작성하고 테스트 코드를 통과시켜줘"
Step 3. 작업 완료 후 메인에서 1초 머지 & 청소
git merge feat/auth && git worktree remove ../wt-auth
✓ 실습 결과: 메인 작업 중단 없이 백그라운드 모듈 완성 & 머지 다음 챕터: 비용 최적화 ➔
🚀 실습 테이크어웨이: 에이전트가 코딩하는 동안 인간이 기다리지 마세요. Worktree로 3개의 이슈를 동시에 던지고 지휘하세요.
