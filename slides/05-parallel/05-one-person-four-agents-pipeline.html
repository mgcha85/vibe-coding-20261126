💡 핵심: 에이전트가 테스트를 통과할 때까지 스스로 자가 치유(Self-healing)하므로 인간의 개입 시간 최소화!
📋 4단계 실전 오케스트레이션 레시피 Actionable Guide
1️⃣ 태스크 잘게 쪼개기 (Divide & Decouple) 기획 단계
의존성이 없는 3~4개 단위로 이슈 분할 (예: 1. Stripe 결제 모듈, 2. 관리자 대시보드 UI, 3. E2E 테스트, 4. DB 인덱스 튜닝).
2️⃣ 비동기 프롬프트 투척 (Fire & Forget) 위임 단계
각 워크트리마다 에이전트를 배치하고 프롬프트 실행 후 AI 응답을 기다리지 않고 즉시 다음 워크트리로 이동.
3️⃣ 컴파일러 & 테스트 기반 자가 검증 (Self-Healing) 자동 품질 게이트
에이전트가 go test, cargo test, pytest가 100% 녹색(PASS)을 띄울 때까지 내부 루프 수행.
4️⃣ 리뷰어로서의 머지 (Review & Integrate) 최종 통합
인간은 코드를 직접 타이핑하는 것이 아니라, 에이전트가 통과시킨 테스트 결과와 Git Diff만 검토하고 PR 머지 클릭!
📢 발표 핵심 멘트: "바이브 코딩 1단계가 '좋은 프롬프트 주기'였다면, 2단계는 '여러 에이전트를 동시에 돌리는 비동기 작업 파이프라인 구축'입니다."
