Chapter 04. 툴체인 · 4.12 웹 에이전트 인프라 AI-FIRST BROWSER RUNTIME · ASIDE vs EGO-LITE

AI 브라우저 패러다임 : Aside vs ego-lite 비교 분석

단순 챗봇 검색이나 빈 샌드박스를 넘어, 개발자의 로그인 세션과 권한을 상속받아 실제 웹 대시보드(Supabase, Stripe, AWS)를 백그라운드에서 직접 조작하는 차세대 브라우저 아키텍처입니다.

🌐 기존 일반 브라우저 Chrome / Safari
인간의 시각 렌더링 및 수동 마우스/키보드 클릭에만 최적화된 단일 사용자 GUI
  • × 에이전트 제어 불가: 외부 AI가 세션이나 내부 탭을 조작할 공식 통로 부재
  • × 수동 복붙 병목: 개발자가 직접 콘솔 로그나 문서를 긁어서 프롬프트에 투척
통제 주체: 100% 인간 수동 조작
🤖 기존 헤드리스 자동화 Playwright / Puppeteer
E2E 테스트 목적의 완전 격리된 일회성 클린 샌드박스 인스턴스
  • × 로그인/2FA 장벽: 쿠키·세션이 없어 Google SSO, OTP, Captcha에서 100% 좌절
  • × 토큰·레이턴시 폭증: 매 액션마다 CLI를 거치며 거대한 HTML/DOM 왕복 오버헤드
통제 주체: 단절된 스크립트 (세션 없음)
⚡ 차세대 AI 에이전트 브라우저 Aside & ego-lite
인간과 에이전트가 하나의 브라우저에서 공존하며 권한을 상속하는 하이브리드 아키텍처
  • ✓ 로그인 세션 상속: Chrome 프로필을 승계해 로그인된 채로 대시보드 즉각 제어
  • ✓ 작업 공간 격리: 인간의 서핑 탭을 방해하지 않고 백그라운드 독립 공간에서 수행
통제 주체: 인간 세션 + 에이전트 자율 백그라운드
🧭 Aside YC S24 · General Browser Agent
Chromium-based
"자동 웹 업무 수행 + 로컬 마크다운 기억(Aside Memory)의 결합"
🎯 Direct Browser Automation 자연어 지시로 다단계 웹 폼 작성, 관리자 대시보드 검증, 복합 검색 및 크로스 사이트 데이터 추출을 자율적으로 완수.
🧠 Aside Memory (로컬 마크다운 영속화) 방문한 웹페이지와 문제 해결 맥락을 기기 로컬에 마크다운으로 자동 인덱싱 → "지난주 OAuth 401 해결 문서 찾아줘" 자연어 시맨틱 인출.
🔌 확장성 & 연동 Claude Code, Cursor, 터미널 CLI와 상호 작용 가능하며 비개발자 업무 자동화부터 개발자 기술 리서치까지 폭넓은 지원.
주요 강점: 브라우징 지식의 로컬 메모리화 & 멀티모달 자율 조작 비정형 리서치 최적
🚀 ego-lite Citro Labs · Developer-First Agentic Browser
Lightweight Chromium
"Task Spaces 물리 격리 + 초저토큰 CDP 직결 제어 런타임"
🛡️ Isolated Task Spaces (제로 탭 오염) 개발자가 서핑 중인 활성 탭을 1초도 뺏지 않음. 에이전트 전용 백그라운드 Space에서 독립 탭을 열어 스크래핑/테스트 수행.
⚡ CDP & Direct JS Execution (초저토큰) 비효율적인 CLI 턴 왕복을 배제하고 Chrome DevTools Protocol(CDP)과 내장 JavaScript 헬퍼로 브라우징 루틴을 최소 토큰에 초고속 실행.
📦 Agent Skill 원터치 연동 npx skills add citrolabs/ego-lite 명령 한 줄로 Claude Code, Cursor, Codex 환경에 에이전트 브라우저 즉시 바인딩.
주요 강점: 개발자 탭 무간섭 · CDP 고속 제어 · 스킬 생태계 직결 바이브 코딩 런타임 최적
💡 KEY TAKEAWAY 바이브 코딩의 실행 영역은 로컬 터미널에 머물지 않습니다. AI 브라우저는 인증된 클라우드 콘솔(Supabase, Stripe, AWS)과 로컬 에이전트를 연결하는 차세대 웹 액션 하네스(Web Action Harness)입니다.
Aside (리서치/메모리) · ego-lite (개발자 격리 런타임)
