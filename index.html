01. 점진적 타이핑(Gradual Typing)의 유연성

Git Worktree : 에이전트별 독립된 물리 작업실

레포지토리를 여러 번 복제하지 않고, 단일 .git 데이터베이스를 공유하며 여러 디렉토리를 동시에 여는 기법입니다.

WORKTREE ORCHESTRATION 컨텍스트 오염 0%

단일 디렉토리에서 여러 에이전트가 동시에 파일을 수정하면 '파일 충돌(Git Lock / File Write Conflict)'과 '프롬프트 컨텍스트 오염'이 발생합니다. Worktree는 이를 물리적으로 완벽 차단합니다.

✓ 1개의 Git 레포로 3개 이상의 IDE 창을 띄워 각각 다른 AI 에이전트 가동
WHY WORKTREE?

복제(Clone) vs Worktree 비교

❌ git clone 3번 하기
• 디스크 용량 3배 낭비 (수 GB 복제)
• 커밋/푸시를 따로 하고 remote를 통해 머지해야 함
• 세팅 시간 5~10분 소요
✅ git worktree 1초 생성
• 디스크 추가 0바이트 (히스토리 공유)
• 메인 레포에서 git merge 즉시 가능
• 명령어 1줄로 0.5초 만에 작업실 생성/삭제
💡 AGENTS.md에 "worktree에서 작업하라"고 명시해두면 에이전트가 격리된 공간에서만 안전하게 작업합니다.
💡 지휘자의 사고방식: 에이전트를 한 명만 부리는 사람은 '코더'이고, 워크트리로 3명을 동시에 부리는 사람은 '팀장'입니다.
